SQL & Database Architecture

  • كتابة استعلامات SQL متقدمة تشمل التجميعات، Joins المعقدة، و Window Functions (`ROW_NUMBER`, `DENSE_RANK`).
  • بناء نماذج البيانات على المخطط النجمي (Star Schema) والمخطط الثلجي (Snowflake Schema).
  • فهم عميق لمفاهيم Normalization و Denormalization وضبط Data Grain لرفع كفاءة الداشبورد.
  • أتمتة عمليات Extraction, Transformation, and Loading (ETL) للحصول على بيانات جاهزة للتحليل.
